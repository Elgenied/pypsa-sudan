# Data rights and attribution

The MIT license at repository root covers **original project code only**. It does not relicense source reports, downloaded databases, map geometry or third-party software. This file records observed terms and is not a substitute for checking terms at release time.

| Material | Observed terms | Release handling |
|---|---|---|
| World Bank AICD transmission ZIP/XML | Catalog states [CC BY 4.0](https://datacatalog.worldbank.org/search/dataset/0067111/sudan-electricity-transmission-network) | Retain attribution, source date, original attributes and notices of modifications/clipping |
| WRI GPPD | README states [CC BY 4.0 for the database](https://github.com/wri/global-power-plant-database) | Attribute WRI and retained original sources; mark selection, matching and corrections |
| Natural Earth outline | [Public domain](https://www.naturalearthdata.com/about/terms-of-use/) | Attribution included voluntarily; disclose scale and limitations |
| World Bank status report | PDF page 2 permits noncommercial reproduction with attribution; other rights retained | PDF is supplied locally for study and excluded from Git by default. Link to the official original in a public release; review rights before redistributing reports |
| World Bank diagnostic report | Its own copyright/permissions notice governs | Source link and local reference copy; PDF excluded from Git by default |
| Historical openAFRICA/OSM and future OSM-derived data | openAFRICA record lists ODbL 1.0; OSM requires attribution and applicable share-alike compliance | No such geometry was successfully downloaded for this version. Review database/derived-database obligations before incorporating future extracts |
| UNDP 2026 study | Publisher terms apply | PDF download failed; publication-page link only |
| Project input assumptions | Original illustrative choices | Mark them as assumptions, never as official Sudan statistics |

Suggested dataset attribution:

"Plant facts transcribed and reconciled from World Bank, Updates of Electricity and Petroleum Report in Sudan (August 2024 status; 2025 publication). Selected historical locations from WRI Global Power Plant Database. Historical network context from World Bank/AICD. Country outline from Natural Earth. Regional aggregation, assumptions and errors in this model are the responsibility of the model authors."

Do not describe the whole combined data bundle as MIT-licensed. Preserve the distinction between raw source material, extracted factual records, derived geospatial layers and original code. Public data access is not the same as unrestricted redistribution.
